# ציר לשער מדרגות – חלק נקבה לקיר

תחליף לחלק הפלסטיק הלבן שנשבר. הפין המתכתי (בצורת L) של השער יורד אנכית לתוך החור, והקצה שלו נשען על רצפת החור. מדפיסים שניים: אחד לציר העליון ואחד לתחתון.

## קבצים
- `gate_hinge_socket.stl` – מוכן להדפסה.
- `gate_hinge_socket.scad` – מקור ב-OpenSCAD עם פרמטרים לשינוי.
- `build_stl.py` – מייצר את ה-STL מחדש (`pip install trimesh manifold3d`).

## מידות (ברירת מחדל)
| | |
|---|---|
| קוטר החור | 8.3 מ"מ (החלק הרחב של הפין 7.9 מ"מ, הצר 5 מ"מ) |
| עומק החור | 31 מ"מ: כל הרגל הישרה של הפין נכנסת לשרוול. רצפה 3 מ"מ וחור ניקוז |
| מרחק מרכז החור מהקיר | 9 מ"מ (בערך כמו בחלק המקורי) |
| ברגים | **אותם חורים קיימים בקיר**, 31 מ"מ בין המרכזים. החור העליון הוא חריץ אנכי (±1.5 מ"מ) |
| מיקום השרוול | **משמאל לברגים** כשעומדים מול הקיר, 13.4 מ"מ לצד, כך שהוא יכול לשבת בגובה המקורי ושני הברגים עדיין נגישים |
| גובה השער | קצה הפין נשען 9 מ"מ מתחת למרכז הבורג התחתון (`tip_below_screw`), כמו הרצפה בחלק המקורי (הערכה מהתמונות) |

כדי שהשרוול יהיה מימין לברגים, משנים את `sleeve_side` ל-1-. אם הגובה לא מדויק, משנים את `tip_below_screw`. אם המרחק בין החורים בקיר שונה, משנים את `screw_spacing`. אם הפין נכנס בקושי, מרחיבים את החור במקדח 8.5.

## הדפסה
- להדפיס **עומד**, בדיוק כמו במודל: הקצה התחתון של הלוחית על המשטח והחור פונה למעלה. בכיוון הזה השכבות נושאות את המשקל ולא נפרדות. לא צריך תמיכות (המשולש שמתחת לזרוע בזווית 45°).
- PETG או ABS/ASA עדיפים (PLA מתאים, אבל עלול להתעוות לאורך זמן תחת עומס).
- 4 קירות (perimeters) לפחות ו-40% מילוי או יותר.

## התקנה
מבריגים לחורים הקיימים: קודם את הבורג התחתון (העגול), ואחר כך את העליון (בחריץ). מרימים את השער ומורידים את שני הפינים לתוך השרוולים.
