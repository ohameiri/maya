# ציר לשער מדרגות – חלק נקבה לקיר

תחליף לחלק הפלסטיק הלבן שנשבר. הפין המתכתי (בצורת L) של השער יורד אנכית לתוך החור, והקצה שלו נשען על רצפת החור. מדפיסים שניים: אחד לציר העליון ואחד לתחתון.

## קבצים
- `gate_hinge_socket.stl` – מוכן להדפסה.
- `gate_hinge_socket.scad` – מקור ב-OpenSCAD עם פרמטרים לשינוי.
- `build_stl.py` – מייצר את ה-STL מחדש (`pip install trimesh manifold3d`).

## מידות (ברירת מחדל)
| | |
|---|---|
| קוטר החור | 9.5 מ"מ (בקצה הפין יש צווארון של כ-8 מ"מ) |
| עומק החור | 21 מ"מ, עם רצפה של 3 מ"מ וחור ניקוז של 3 מ"מ |
| מרחק מרכז החור מהקיר | 18 מ"מ |
| לוחית לקיר | 26 × 80 × 5 מ"מ |
| ברגים | 2 ברגים שקועים 4 מ"מ, במרחק 64 מ"מ זה מזה |

המרחק בין השער לקיר נקבע בעיקר לפי כמה הבורג המושחל של השער מוברג פנימה, אז אפשר לכוונן אותו גם אחרי ההתקנה.

## הדפסה
- להדפיס **עומד**, בדיוק כמו במודל: הקצה התחתון של הלוחית על המשטח והחור פונה למעלה. בכיוון הזה השכבות נושאות את המשקל ולא נפרדות. לא צריך תמיכות (המשולש שמתחת לזרוע בזווית 45°).
- PETG או ABS/ASA עדיפים (PLA מתאים, אבל עלול להתעוות לאורך זמן תחת עומס).
- 4 קירות (perimeters) לפחות ו-40% מילוי או יותר.

## התקנה
החורים הישנים בקיר לא מתאימים לחלק החדש, כי כאן הברגים רחוקים יותר זה מזה כדי שהזרוע לא תסתיר אותם. לכן צריך לקדוח חורים חדשים עם דיבלים. מסמנים את המיקום כשהשער מורם ותלוי על שני החלקים, ושני החורים צריכים להיות בדיוק על אותו קו אנכי.
